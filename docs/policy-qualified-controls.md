`test-route-recovery.py --policy-qualified-controls --evidence-dir DIR` separates the normal Startup→Idle policy from control delivery measurements. Normal builds must start at Startup 0 and actually reach Idle 1 before three distinct Idle 1 publications; HITL keeps the requested 1/0/1 exercise. Underglow and buzzer retain 1/0/1. Automatic state transitions remain enabled.

The mandatory `policy-all-owner-audit.json` checks every accepted publication in the complete nine-type managed-variable family, including background or unexpected IDs. Each publication needs its recorded API request clock, successful submitted Packet ID, accepted target list, and matched receipts from every target within 500 ms. Missing origins, missing owners, expiry, or pending-table disappearance cannot qualify a publication. A 30 s global settling barrier is separate from ACK evidence.

The primary emits `[gs-qualification-scope]` from its loaded runtime schema. The auditor independently freezes all nine managed names/IDs and three explicitly excluded typed command names/IDs; a trace cannot omit or relabel managed traffic to avoid the gate. Schema changes require updating and revalidating this mapping.

`FLIGHT_COMMAND`, `VALVE_COMMAND`, and `ACTUATOR_COMMAND` preserve their existing SDK `log_queue` path. Their original receiver checks remain required: Valve startup and Valve/Actuator soak physical status limits default to 2500 ms; FC startup requires the firmware execution counter; RF soak retains its existing 500 ms reliable round gate. The new managed-family audit makes no additional per-packet 500 ms claim for these excluded typed commands, and lists their observed obligations explicitly. Simulation/receiver validation must also succeed before the runner reports PASS.

The runner writes audit evidence even when simulation validation fails and preserves that original failure. The feature is opt-in; the default fixture and gates remain unchanged. Keep generated evidence outside source repositories.

Each simulation stage snapshots existing capture paths before starting. The auditor requires exactly one new `bay-<numeric-id>/groundstation-host.log` (or the legacy direct log) and writes its audit in the host-owned evidence root with that capture basename as a suffix. Multiple new captures, no new capture, or an existing audit for the selected capture fail explicitly. Captured files and simulator-owned directories remain read-only and retain their permissions. Long-test stages retain separate, exclusively created audit files; earlier captures and failed audits are never selected by timestamp or overwritten.

The initial primary `publish_current` call has a separate, one-shot local-cache lifecycle before RX workers start. Trace proof must show two configured sides, zero learned readers/pending owners, nine successful real API submissions, and the exact nine resulting cached Packet IDs before the context seals. Only these verified initial cache bindings may lack a remote admission; the report labels them `LOCAL_CACHE_PRIMED`, never delivered. Every accepted managed ID still needs all owner receipts within 500 ms, including any initial-cache ID that actually acquires a receipt contract. Later requests, other threads, a zero clock, or an absent route cannot inherit this exception. Discovery and actual firmware cache checks remain separate requirements.
