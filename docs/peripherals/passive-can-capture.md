# Bounded passive CAN capture

Set `FIRMWARE_SIM_CAN_TRACE_DIR` and `FIRMWARE_SIM_CAN_TRACE_UNTIL_MS` (1–3600000) explicitly to record each linked controller's transmitted and observed received frames. The bay supplies stable `<link>-<node>-<peripheral>` names. Without the directory variable the model attaches no transmitter subscriber, opens no files, and adds no timer.

Each direction writes an exclusive-create `SEDSCAN1` binary file, bounded to 64 MiB, plus a status sidecar. A capture is complete only after observed traffic passes its inclusive time horizon and its sidecar says finished, uncapped and unfaulted with matching record counts. An interrupted or quiet-tail capture remains incomplete. Receive records precede INIT/filter/FIFO checks: they prove a bus observation, not firmware acceptance. Writer failures invalidate evidence while allowing CAN delivery to continue.

The 32-byte little-endian header is `<8sIIQQ>`: magic, version1, record-size80, horizon in microseconds, maximum bytes. Each fixed80-byte record is `<QIBBH64s>`: virtual microseconds, CAN identifier, flags (FD1, extended2, remote4, BRS8), payload length, reserved0 and zero-padded payload. Use `scripts/analyze-can-trace.py` to check status/structure and reassemble bounded physical fragments. Unsupported compact transport kinds remain explicit unknowns; use the exact SDK decoder for their interpretation.

Optional `FIRMWARE_SIM_CAN_PROBES_<UPPERCASE_TRACE_NAME>` accepts at most32 comma-separated `name=0xSRAM_ADDRESS` entries. Hyphens/dots in the trace name become underscores. Aligned SRAM reads occur on observed traffic at most once per virtual second, without extra stepping or timers. The JSONL is a diagnostic snapshot, not an atomic firmware transaction or a complete publication history. Validate its coverage separately; failed reads or writes close it without changing CAN delivery.

`tests/can-trace/CanTrace.csproj` exercises the actual writer's inclusive horizon, metadata/padding, file cap, interrupted/error status and refusal to overwrite existing evidence. Actual Renode controller timing, finite FIFO and reset contracts must also be run with tracing disabled/enabled before using a new diagnostic image. Trace images are distinct artifacts from prior qualified images; never relabel their source hashes or assume a new capture explains an uncaptured earlier loss.
